# ЛР1

Маємо модель:

```
X -> Linear(4, 8) -> ReLU -> Linear(8, 3)
```

Вихідні логіти перетворюємо у ймовірності через softmax, тобто експонента логіта поділена на сумму експонент логітів.

Лосс отримаємо чезер крос-енропію, тобто -log(p_target).

І тому, градієнт вихідного слою, доволі зручно рахувати, як матриця ймовірностей - one hot, тобто для кожного рядку віднімаємо 1 від ймовірності правильного класу.
Але, так як через forward пропускаємо N елемнтів, тому цей градієнт усереднюємо, щоб отримати середній градієнт похибки для кожного елемента. Інакше отримаємо сумму градієнтів похибки.

## Forward

```
Z1 = X @ W1 + b1   (n x 4) @ (4 x 8) = (n x 8)
A1 = ReLU(Z1)      (n x 8)
Z2 = A1 @ W2 + b2  (n x 8) @ (8 x 3) = (n x 3)

P = softmax(Z2)    (n x 3)
```

## Backward

Тут, ланцюгове правило для похідних. Наприклад, нас цікавить dL/dW2:

```
dL/dW2 = dL/dZ2 * dZ2/dW2
```

Де `dL/dZ2` це (P - one_hot) / n.
І також `Z2 = A1 @ W2 + b2` => `dZ2/dW2 = A1`.

І головне, щоб розмірність градієнта була рівна розмірності самого обʼєкта.

```
dZ2 = (P - one_hot(y)) / n
dW2 = A1.T @ dZ2
db2 = sum(dZ2, axis=0)

dA1 = dZ2 @ W2.T

dZ1 = dA1 * (Z1 > 0)
dW1 = X.T @ dZ1
db1 = sum(dZ1, axis=0)
```

| Масиви                   | Розмірність |
| ------------------------ | ----------- |
| `X`                      | `n x 4`     |
| `Z1`, `A1`, `dA1`, `dZ1` | `n x 8`     |
| `logits`, `P`, `dZ2`     | `n x 3`     |
| `W1`, `dW1`              | `4 x 8`     |
| `b1`, `db1`              | `8`         |
| `W2`, `dW2`              | `8 x 3`     |
| `b2`, `db2`              | `3`         |

## Звірка з PyTorch

Ті самі початкові ваги скопійовано в `torch.nn.Linear` з транспонуванням, оскільки PyTorch зберігає їх у форматі `(out, in)`.

Loss NumPy: `1.4562007801142816`, loss PyTorch: `1.4562007801142818`. Допуск: `1e-12`.

| Величина | Максимальна абсолютна різниця | Результат |
| -------- | ----------------------------: | --------- |
| Loss     |                    `2.22e-16` | Y         |
| `dW1`    |                    `2.78e-17` | Y         |
| `db1`    |                    `2.78e-17` | Y         |
| `dW2`    |                    `5.55e-17` | Y         |
| `db2`    |                    `1.11e-16` | Y         |

## Перевірка чисельного градієнта

Беремо один параметр, наприклад `W1[0, 0]`. Зсуваємо його на `epsilon` вгору й вниз від початкового значення та двічі рахуємо loss. Різницю цих значень ділимо на `2 epsilon`, і отримане число порівнюємо з `backward()`.

| Параметр   |      `backward()` |  Чисельна похідна | Абсолютна різниця | Результат |
| ---------- | ----------------: | ----------------: | ----------------: | --------- |
| `W1[0, 0]` | `-0.019920184331` | `-0.019920184391` |        `6.03e-11` | Y         |
| `b1[0]`    | `-0.070566111584` | `-0.070566111621` |        `3.63e-11` | Y         |
| `W2[0, 0]` |  `0.135230208605` |  `0.135230208698` |        `9.22e-11` | Y         |
| `b2[0]`    |  `0.085521644842` |  `0.085521644988` |        `1.46e-10` | Y         |
